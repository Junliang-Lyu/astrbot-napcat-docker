# 阿尔丹马娘资讯与卡池 MVP 实施说明

## 目标

给阿尔丹增加一个很小的赛马娘游戏内资讯能力，先解决群友最常问的“现在有什么活动 / 现在卡池是什么 / 最近官方有什么公告”。

第一版重点是低风险、低维护、可验证，不追求完整攻略机器人。

## 设计原则

- 先做被动查询，不默认主动刷屏。
- 先支持一个服务器来源，建议默认日服，并在回复里写清楚“日服”。
- 回复只给短摘要、时间、来源链接，不搬运官方公告全文或攻略站全文。
- 所有信息都要带来源，避免阿尔丹编造。
- 先做稳定可用的小功能，不做大数据库和强度推荐。

## 第一版命令

### 1. `阿尔丹 马娘资讯`

主入口，回答“目前赛马娘发生了什么”。

示例输出：

```text
马娘资讯（日服）：

当前卡池：
- 育成马娘：xxx / xxx
- 支援卡：SSR xxx / SSR xxx
- 结束：5/28 11:59，剩余约 3 天

近期重点：
- 新活动「xxx」进行中，结束：5/29 04:59
- 官方发布维护公告：5/22 11:00 - 17:00

来源：官方公告 / Umapyoi
请以游戏内公告为准。
```

说明：

- `马娘资讯` 负责“人话总结”。
- 当前卡池、即将结束、重要公告都可以在这里简短合并。
- 不需要列太多内容，建议最多 3-5 条。

### 2. `阿尔丹 当前卡池`

快捷入口，只回答抽卡相关信息。

示例输出：

```text
当前卡池（日服）：

育成马娘：
- xxx
- xxx

支援卡：
- SSR xxx
- SSR xxx

结束时间：5/28 11:59
剩余时间：约 3 天

来源：Umapyoi / 官方公告
请以游戏内公告为准。
```

说明：

- 这是第一版优先级最高的功能。
- 输出不要夹带抽卡建议，除非后续另做攻略模块。
- 不要说“必抽”“跳过”这类强度判断。

### 3. `阿尔丹 马娘公告`

原始公告列表，方便用户点开原文。

示例输出：

```text
最近官方公告（日服）：

1. 5/20 12:00 新活动「xxx」开启
https://...

2. 5/20 12:00 新卡池登场
https://...

3. 5/19 18:00 维护通知
https://...

只显示标题、时间和链接；详细内容请看原公告。
```

说明：

- 这个命令不负责长摘要。
- 第一版显示最近 3-5 条即可。
- 只抓标题、时间、链接，避免复制公告全文。

## 暂缓项

第一版先不要做这些：

- `阿尔丹 即将结束` 独立命令。
- 主动每日播报。
- 卡池 / 活动订阅提醒。
- 攻略爬取和攻略总结。
- 支援卡强度推荐。
- 技能配法推荐。
- 冠军赛 / LoH 攻略。
- 完整马娘、支援卡、技能数据库。
- 游戏账号登录、抓包、客户端自动化。

后续如果要做提醒，可以把“即将结束”升级为：

```text
阿尔丹 结束提醒
阿尔丹 订阅卡池提醒
阿尔丹 取消卡池提醒
```

但不建议放进第一版。

## 马娘数据 / 支援卡数据的处理建议

第一版不要完整录入角色库和支援卡库。

可以只做一个很小的别名表，用来改善显示和搜索：

```text
目白阿尔丹 / 阿尔丹 / メジロアルダン
支援卡中文名 / 日文名 / 常用简称
```

原因：

- 完整数据库维护成本高。
- 中文别名和玩家简称不稳定。
- 支援卡评价涉及攻略观点，容易答错。
- 第一版目标是资讯和卡池，不是百科查询。

如果后续要加数据查询，建议第二阶段再做：

```text
阿尔丹 查马娘 目白阿尔丹
阿尔丹 查支援卡 xxx
```

并且只输出基础信息和来源链接，不做强度结论。

## 数据源建议

优先级：

1. Umapyoi API
   - 用于卡池、新闻等结构化数据。
   - 文档：https://umapyoi.net/docs/index.html
   - 路由表：https://umapyoi.net/docs/http-routingtable.html

2. 官方 News
   - 用于公告标题、时间、原文链接校验。
   - 地址：https://umamusume.jp/news

3. GameTora / UmaTracker
   - 第一版只作为人工参考或后续扩展参考。
   - 不建议第一版自动爬全文。

注意：

- 官方公告和攻略站内容不要全文搬运。
- QQ 回复里只放短摘要、时间、链接。
- 如果接口失败，要明确提示“暂时查不到”，不要让模型猜。

## 技术结构建议

沿用现有 AstrBot / Python 体系，尽量少改。

建议结构：

```text
data/plugins/astrbot_plugin_umamusume_info/
  main.py
  sources/
    umapyoi.py
    official_news.py
  storage.py
  formatter.py
  config.py
```

核心模块：

- `main.py`
  - 注册命令：`马娘资讯`、`当前卡池`、`马娘公告`
  - 负责接 AstrBot 消息事件。

- `sources/umapyoi.py`
  - 拉 Umapyoi API。
  - 输出统一结构，不直接拼 QQ 文本。

- `sources/official_news.py`
  - 拉官方公告列表。
  - 只保留标题、时间、链接。

- `storage.py`
  - SQLite 缓存。
  - 存来源、标题、链接、开始 / 结束时间、更新时间。
  - 做简单去重。

- `formatter.py`
  - 负责把结构化数据变成 QQ 短回复。
  - 控制长度，避免刷屏。

- `config.py`
  - 数据源开关。
  - 默认服务器：日服。
  - 缓存 TTL。

## SQLite 缓存建议

第一版可以非常简单：

```sql
sources(
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  base_url TEXT,
  enabled INTEGER NOT NULL DEFAULT 1
)

events(
  id INTEGER PRIMARY KEY,
  source TEXT NOT NULL,
  external_id TEXT,
  category TEXT NOT NULL,
  title TEXT NOT NULL,
  url TEXT,
  starts_at TEXT,
  ends_at TEXT,
  fetched_at TEXT NOT NULL,
  raw_json TEXT
)
```

`category` 可以先用：

```text
gacha
event
maintenance
news
campaign
unknown
```

去重规则：

```text
source + external_id
```

如果没有 `external_id`，再退到：

```text
source + title + url
```

## MVP 实现顺序

1. 新建插件骨架。
2. 实现 Umapyoi 当前卡池拉取。
3. 实现 `阿尔丹 当前卡池`。
4. 实现官方公告列表拉取。
5. 实现 `阿尔丹 马娘公告`。
6. 实现 `阿尔丹 马娘资讯`，把卡池和最近公告合并成短摘要。
7. 加 SQLite 缓存和失败兜底。
8. 做最小烟测。

## 失败兜底

接口失败时：

```text
阿尔丹现在暂时查不到马娘资讯，可能是数据源连接失败。
可以稍后再试，或直接查看官方公告：https://umamusume.jp/news
```

缓存存在但已过期时：

```text
这是阿尔丹上次缓存到的马娘资讯，可能不是最新：
...
更新时间：5/20 09:00
```

没有数据时：

```text
阿尔丹暂时没有查到当前卡池信息。
请以游戏内公告为准。
```

## 验收标准

最小验收：

- `阿尔丹 当前卡池` 能返回当前卡池、结束时间、来源。
- `阿尔丹 马娘公告` 能返回最近 3-5 条公告标题、时间、链接。
- `阿尔丹 马娘资讯` 能合并当前卡池和近期重点，长度适合群聊。
- 数据源失败时不会编造内容。
- 回复里明确写服务器，例如“日服”。
- 回复里带来源，并提示“请以游戏内公告为准”。
- 不读取 `.env`、QQ 私聊/群聊数据库、token、cookie。
- 不改 `docker-compose.yml`，除非后续明确需要。

## 风险

- Umapyoi 是社区 API，可能变更或不可用，所以必须有缓存和失败提示。
- 官方公告页面结构可能变化，解析逻辑要保持保守。
- 不同服务器卡池不同，第一版必须明确只支持哪个服务器。
- 翻译和中文简称可能不稳定，第一版不要承诺完整中文化。
- 主动推送容易变成群消息噪音，第一版先不要默认开启。
